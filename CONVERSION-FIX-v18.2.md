# ETHAN Office v18.2 Conversion Fix
- Office/PDF binary data can no longer be displayed as text.
- DOC/DOCX, XLS/XLSX, PPT/PPTX and PDF file signatures are checked.
- Wrong, renamed or damaged files show a normal error.
- Text converters accept readable text only.
- Advanced gateway supports both JSON download links and direct converted-file responses.
- Failed conversion never dumps raw bytes onto the page.
