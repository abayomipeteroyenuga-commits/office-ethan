# Ethan Office v18.0 — Expanded Office-Style Productivity

This build expands Ethan Word, Ethan Excel and Ethan Presentation with broader desktop-office style workflows while keeping Ethan branding.

## Ethan Word
- File, Home, Insert, Draw, Design, Layout, References, Mailings, Review, View tabs
- Rich text and paragraph formatting
- Page size/orientation/margins/columns, headers, footers, page numbers, watermark, borders, themes
- Tables, images, TOC, footnotes, index, bookmarks, cross references, citations and bibliography
- Word count, spellcheck toggle, find/replace, formatting marks, zoom and print layout
- Envelopes, labels and basic mail merge with recipient fields
- Signature line and drawing/highlight workflow
- Print/PDF and downloadable document copy

## Ethan Excel
- Home, Insert, Formulas, Data, Page Layout, Review, View, File tabs
- 20-column worksheet, formulas and cell references
- SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, IF and ROUND support
- Formatting, number formats, fill, clear, conditional formatting
- Sorting, filters, find/replace, remove duplicates, validation dropdowns, text-to-columns
- Table formatting, charts, pivot-style summary and simple goal-seek estimate
- Page setup, print area, orientation, margins, scaling and print/PDF
- Freeze panes, zoom, protection and formula checking
- CSV import/export and AutoSave

## Ethan Presentation
- Home, Insert, Design, Transitions, Animations, Slide Show, Record, Review, View, File tabs
- Draggable/resizable title and body boxes
- Layouts, themes, slide size and background
- Text boxes, shapes, images, table/chart content placeholders
- Transitions and simple object animation
- Speaker notes, narration notes, rehearsal timing and presenter view
- Slide sorter, normal view, notes view and custom show
- Export outline and print/PDF

## Scope note
Microsoft 365 includes a very large proprietary ecosystem such as VBA/macros, advanced Power Query/Power Pivot, enterprise collaboration, cloud co-authoring, add-ins, complex SmartArt, advanced chart engines, desktop printer drivers, Exchange integration, and hundreds of specialised functions. A browser PWA cannot be an exact copy of every Microsoft feature. Ethan Office v18.0 therefore focuses on implementing the major everyday document, spreadsheet and presentation workflows natively under Ethan branding rather than reproducing Microsoft's proprietary UI or code.
